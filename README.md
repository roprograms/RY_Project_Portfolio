# Rohan Yarlagadda — Portfolio

Personal project portfolio built with [Quarto](https://quarto.org) and hosted on GitHub Pages.

## Editing

- `_quarto.yml` — site title, navbar tabs, theme
- `index.qmd` — home page (bio, project cards, resume)
- `experience.qmd`, `projects.qmd`, `personal.qmd` — section pages
- `posts/` — blog posts
- `images/` — photos and `Resume.pdf`
- `styles.css` — custom styling

## Commands

```bash
quarto preview            # live local preview
quarto publish gh-pages   # build and publish to GitHub Pages
```
